# Janma Kundali Lab

A free, mobile-friendly workspace for comparing Janma Kundali calculators and recording calculation differences.

## Included

- Kundali maker directory
- Search and feature filters
- Standardized birth-data profile
- Quick links to external calculators
- 14-field verification workspace
- Automatic agreement scoring
- Local browser save/restore
- Calculation-method reference stack
- Responsive glassmorphism UI

## Verification settings reference

The application documents a reference approach of:

- Sidereal zodiac
- Lahiri / Chitrapaksha ayanamsa
- True Node
- Whole Sign houses
- D1, D9, Nakshatra and Vimshottari Dasha outputs

The current verification workspace records and compares outputs from external calculators; it does not claim that astrological predictions are scientifically validated.

## Files

- `index.html` — application UI
- `style.css` — responsive UI
- `data.js` — calculator/resource metadata
- `app.js` — search, comparison profile and verification logic
